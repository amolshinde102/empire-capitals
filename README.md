# Empire Capitals – Professional Trading Website

Welcome to the official repository of **Empire Capitals**, a cutting-edge trading education platform offering courses in stock market, forex, and technical analysis.

## 🌐 Live Site

Visit the website:  
👉 [https://amolshinde102.github.io/empire-capitals](https://amolshinde102.github.io/empire-capitals)

---

## 🚀 Project Features

- Hero section with parallax and trading animations
- Responsive design for desktop and mobile
- Interactive course sections with batch schedules
- Trainers and Testimonials carousel
- Gallery with horizontal scroll
- Contact form with WhatsApp integration
- Smooth snap scroll transitions with fade effects

---

## 🛠️ Technologies Used

- **Vite** – Fast bundler and dev server
- **React + TypeScript** – Modern frontend
- **Tailwind CSS** – Utility-first responsive design
- **shadcn/ui** – Component library
- **Radix UI + Lucide Icons** – UI/UX enhancements
- **gh-pages** – GitHub Pages deployment
